# Umrah Package Calculator

## Overview
A comprehensive web application for travel agencies to calculate customized Umrah pilgrimage packages with automatic pricing calculations. Features accommodation options, flight and visa charges, with separate rate management for Makkah and Medina stays.

## Key Features
- **Accommodation Calculator**: Automatic rate calculations for sharing/double/triple/quad rooms
- **Flexible Pricing**: Separate room rates for Makkah and Medina
- **Service Options**: Includes flight and visa cost calculations
- **User-Friendly**: Clean interface with real-time cost breakdowns
- **Responsive Design**: Works on desktop and mobile devices

## Technologies Used
- HTML5, CSS3, JavaScript
- Local Storage for session management
- Gradient UI design

## Setup
1. Clone repository
2. Open `index.html` in any modern browser
3. Use default credentials:
   - Username: `admin`
   - Password: `admin`

## Usage
1. Select accommodation options
2. Enter stay duration and room preferences
3. Add flight/visa services if needed
4. Click "Calculate Total Cost" for detailed pricing
